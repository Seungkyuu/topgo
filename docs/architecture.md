# 시스템 아키텍처

Lee&Kim 반자동 견적 시스템의 기술 아키텍처. 요구사항은 `PRD.md`, 엑셀 근거는 `excel-analysis.md` 참조.

## 설계 원칙

- **반자동(Human-in-the-loop)**: 기계는 추출·조회·계산·초안 작성, 사람은 검수·영업 판단·발송 승인. 완전 자동 발송 금지.
- **로컬 엑셀 탈피**: Microsoft Excel COM 자동화는 클라우드에서 불가·비권장. 캐피탈사 계산 로직을 **코드로 이식**해 런타임에 엑셀을 실행하지 않는다.
- **무료 관리형 스택**: 자체 서버·사내망 없음. Vercel·Supabase 등 무료 티어로 구성.
- **어댑터 격리**: 외부 연동(GETCHA·알리고)과 금융사별 계산은 각각 독립 어댑터로 분리해 교체·확장 시 나머지를 건드리지 않는다.

## 기술 스택

| 계층 | 선택 | 이유 |
|---|---|---|
| 프론트 | Next.js (반응형 웹) | 설치 불필요, PC·모바일 브라우저 공용, Vercel 무료 배포 |
| API | Next.js 서버리스 라우트 | 캡처 추출·계산·외부 API 호출을 서버측에서 처리(키 비노출) |
| 캡처 추출 | Claude Vision (Sonnet 5 시작, 검증 후 Haiku 4.5 고려) | 한국어 정형 폼 추출 정확도 |
| 계산 엔진 | TypeScript 모듈 (금융사×상품 어댑터) | 엑셀 로직 코드 이식 |
| DB·저장·인증 | Supabase 무료 티어 (Postgres + Storage + Auth) | 이력·참조데이터 저장, 인증은 나중에 켜기 |
| 할인 조회 | GETCHA 어댑터 | 예전 API 스펙 수령 대기 → 그때까지 stub/수동입력 fallback |
| 문자 발송 | 알리고 SMS/LMS 어댑터 | 발신번호 등록 필요, 서버리스 고정IP 이슈 유의 |

## 전체 워크플로우

```
① 카랩 캡처 업로드
       │  Claude Vision (/api/parse)
② 텍스트 추출·정형화 ─────▶ 저장(DB)      [차량·조건·메타]
       │
③ GETCHA 할인가 조회 (/api/discount)      [어댑터, 스펙 수령 전까지 수동입력 fallback]
       │
④ 계산 엔진 (/api/quote)                  [잔가·보험·세금 사슬, 금융사 어댑터]
       │
⑤ 견적서 생성 (월 렌트료·초기비용·요약)
       │  상담사 검수 (반자동 게이트)
⑥ 알리고 SMS 발송 (/api/send)             [발송 전 승인 필수]
```

## 데이터 모델: 계산 프로파일

프로파일 하나 = 금융사 × 상품 × 연월. 엑셀 분석 결과 단순 파라미터가 아니라 4요소로 구성된다.

```
계산 프로파일
├─ 어댑터 로직   : 그 금융사·상품의 계산 사슬을 코드로 이식 (드물게 변경, 개발자)
├─ 파라미터     : 기준금리·수수료율 등 (매달 변경, 담당자)
├─ 참조 테이블   : 잔가율표·차량모델가·보험요율·공채·취득세 (대량, 엑셀 자동추출 → DB)
└─ 골든 테스트   : 실제 엑셀 출력값 N케이스 (활성화 전 검증 필수)
```

세금·공채·자동차세·취득세는 법정 기준이므로 금융사 공통 모듈로 분리한다.

## 엑셀 템플릿 수명주기

1. **수령·보관**: 캐피탈사 신규 엑셀을 규칙 파일명으로 Google Drive 연월 폴더에 원본 보관.
2. **파라미터·참조 추출**: 스크립트(openpyxl/SheetJS)로 잔가율표·모델가표·금리 등을 DB에 적재. v1 파라미터는 수기 보정 허용.
3. **정합성 검증**: 대표 시나리오 N개를 실제 엑셀에 넣어 얻은 정답값 vs 코드 엔진 계산값 자동 대조 → 시나리오별 ✅/❌.
4. **스테이징 → 활성화**: 전 케이스 통과한 프로파일만 활성. 미검증·만료 프로파일은 상단 경고 배너.
5. **운영**: 견적마다 사용 프로파일 버전을 스냅샷으로 이력 저장(재현성).

> 안전장치: 캐피탈사가 수식 구조 자체를 바꾸면 3단계에서 자동으로 불일치(❌)가 떠 "개발자 개입 필요"를 시스템이 스스로 잡아낸다.

## 캡처 추출 스키마 (카랩 전용)

카랩 상담 카드는 라벨이 붙은 정형 폼이라 추출 정확도가 높다. `/api/parse` 출력 계약:

| 구분 | 필드 | 엔진 역할 |
|---|---|---|
| 차량 | 브랜드·모델·트림·연식 | 모델 DB → 잔가율 조회 키 |
| | 기본가·옵션가·할인·총액 | 차량가 |
| 거래조건 | 구매방식(장기렌트 등) | 상품 필터 |
| | 약정개월수 | 계약기간 |
| | 약정주행거리 | 잔가율 조정 키 |
| | 초기비용/보증금 | 선납 구조 |
| | 정비유형·운전연령·보험(대불)·면책금 | 보험·정비료 산정 |
| 산출 대상(빈칸) | 렌트료(월) | ← 엔진이 계산 |
| Human Touch(빈칸) | 수수료율·추가할인 | 상담사 입력 |
| 메타 | 견적번호·닉네임·전화·지역·메모 | 이력·표시 (개인정보 → 선택 필드 분리) |

## 외부 연동 유의사항

- **GETCHA**: 공개 개발자 API 없음(제휴 문의만). 사용자가 예전에 받은 API 스펙 수령 전까지 어댑터는 stub, v1은 상담사 수동 할인 입력으로 대체.
- **알리고 SMS**: 발신번호 사전 등록 + 발송 서버 IP 화이트리스트 필요. Vercel 서버리스는 고정 IP가 없어 IP 제한 해제 또는 고정IP 프록시 검토. 알림톡은 향후(카카오 비즈채널·템플릿 승인 필요).

## 구현 단계

1. **수직 슬라이스**: 오릭스 운용리스로 캡처추출 → 계산 → 검증 → 견적서 end-to-end 증명.
2. **가로 확장**: 금융사별 대표상품 1개씩 어댑터 추가.
3. **연동 완성**: GETCHA 스펙 수령 시 자동화, 알리고 SMS 발송.
4. **심화**: 상품 다양화, 알림톡, 인증·개인정보 규제 대응.

## 캐피탈 취급 매트릭스 (중요)

캐피탈사마다 **취급 가능한 브랜드·원산지·거래방식이 다르다.** 견적 시 그 차량을
취급하는 캐피탈만 비교 대상에 넣어야 한다(취급 안 하는 캐피탈은 비교에서 제외).

- 원산지(국산/외제)별로 캐피탈 엑셀 **시트/파일이 따로** 존재한다.
- 각 캐피탈은 `capital × dealType × brand(origin)` 능력을 선언한다(`capitals.ts` 확장 예정).

전체 17개 파일 식별 결과 — **캐피탈은 3곳**(오릭스·신한카드·메리츠). 각 캐피탈이
원산지·상품·브랜드로 파일을 쪼갠다. (중복·버전 파일 다수. 국산·EV·특정브랜드 파일은 전부 메리츠.)

| 캐피탈 | 원산지 | 거래방식 | 취급 브랜드 | 엔진 |
| --- | --- | --- | --- | --- |
| 오릭스 | 외제 | 운용·금융리스·할부 | Benz·BMW·Audi·Lexus | ✅ 이식완료 |
| 오릭스 | 외제 | 운용리스 | Tesla Model Y | (동일 엔진) |
| 신한카드 | 외제 | 오토리스(운용&금융) | BMW·Porsche·Audi·BYD | ✅ 운용 이식 |
| 신한카드 | 외제 | 렌터카 | BMW·테슬라·Audi·MINI | 미착수 |
| 메리츠 | 외제 | 운용·금융리스·할부 | Audi·Benz·Porsche·BMW | 미착수 |
| 메리츠 | 외제 | 장기렌트 | 폴스타·테슬라·BYD | ✅ 렌트 코어 |
| 메리츠 | 외제 | 운용리스 | Tesla / BYD 전용 | 미착수 |
| 메리츠 | **국산** | 렌트·운용리스 | 제네시스·현대·기아·KG·쉐보레 | 미착수 |

> 엑셀 → 앱 반영은 **개발 시점 1회성 포팅**(엔진 이식 + 참조데이터 추출)이다.
> 런타임 앱은 엑셀을 읽지 않으며, 매달 변동은 파라미터(금리·잔가) 데이터만 갱신한다.

## 시트 확장 시 기억할 필드 (백로그)

캐피탈·상품별로 시트를 붙일 때 추가로 다뤄야 하는 항목:

- **협력업체(딜러사)**: 브랜드별 딜러를 선택해야 하는 시트가 있다 (예: 벤츠 → 한성모터스, BMW → 바바리안).
  견적서 발행 주체, 딜러 지원금·캐시백 산정에 영향을 줄 수 있다. `브랜드별 딜러사` 시트 참조.
  다른 시트에서 등장하면 반드시 입력/매핑에 반영한다.
- **잔가**: 항상 최대잔가. 모델+기간+약정주행거리로 자동 조회(수동 입력 아님). → `lib/engine/orix/residual.ts`
- 자동차세·보험료·등록세·공채·금리표: 리스료 포함 조건/상품별로 참조테이블에서 조회. (`orix-engine.md` 참조)

## 나중에 확정할 항목 (열어둠)

- 인증·권한 모델(다중 상담사 여부)
- 개인정보 처리: 캡처의 고객 전화·닉네임 저장 범위, Claude 전송, SMS 발송(정보통신망법 수신동의·광고표기)
- 무료 티어 한도 및 유료 전환 시점
