# 오릭스 견적 엔진 (역추적 계산 모델)

오릭스캐피탈 견적 엑셀을 역추적해 코드로 이식한 계산 모델. 상품 3종(운용리스·금융리스·할부).
구현: `lib/engine/orix/` · 검증: `lib/engine/orix/__tests__/` (골든 테스트 14건, 엑셀과 오차 0).

> ⚠ **캐피탈·시트마다 계산 구조가 다르다.** 이 문서와 코드는 오릭스 전용 어댑터이며,
> 메리츠 등 다른 금융사는 각자의 시트를 별도로 역추적·이식한다(금융사별 어댑터 원칙).
> 오릭스 내에서도 세 상품의 공식이 서로 다르다(아래).

## 상품별 공식 요약

| 상품 | 엑셀 열 | 잔가(fv) | 보증금 | 수수료 | 월납입 공식 |
|---|---|---|---|---|---|
| 운용리스 | X | 있음(최대잔가) | 있음 | — | `PMT(금리/12, 기간, −(이용−보증), 잔가−보증)` |
| 금융리스 | Z | 0 | 없음 | — | `PMT(금리/12, 기간, −이용금액, 0)` |
| 할부 | AB | 0 | 없음 | 있음 | `PMT(금리/12, 기간, −(이용+수수료), 0)` |

- **잔가는 항상 최대잔가**로 전달한다(운영 정책). 추후 고잔가군 잔가율표에서 최대값 자동 조회.
- 이용금액 = 취득원가 − 선납금. 취득원가 = 차량가 + 취득원가포함 세금(별도부담이면 0).

## 계산 사슬 (핵심)

```
과세표준  X24 = ROUNDDOWN(차량가 / 1.1, -2)
취득세    AI7 = ROUNDDOWN(과세표준 × 7%, -1)
취득원가  X30 = 차량가 + 취득세 + 부대비용(100,000)
이용금액  X31 = 취득원가 − 선납금
보증금    X33 = ROUNDUP(차량가 × 보증금율, -3)
잔가      X37 = ROUNDUP(차량가 × 잔가율, -3)

월리스료  X42 = ROUNDUP( PMT(금리/12, 기간,
                            pv = −(이용금액 + 수수료 − 보증금 − 선수),
                            fv = 잔가 − 보증금),
                        -2 ) + 선수리스료조정
```

총리스료(월) K23 = 순수리스료(X42) + 자동차세(월) + 보험료(월).
(자동차세·보험은 "리스료 포함" 상품에서만 가산. 아래 골든 케이스는 미포함이라 K23 = X42.)

## 금융리스 상세

```
취득원가  Z30 = 차량가 + 취득원가포함 세금
이용금액  Z31 = 취득원가 − 선납금
월리스료  Z42 = ROUNDUP( PMT(금리/12, 기간, −이용금액, 0), -2 )   ← 잔가·보증금 없음
```

골든 케이스 (G 400d): 차량가 181,600,000 / 60개월 / 금리 5.5% / 선납 100,000,000
→ 이용금액 81,600,000 → **월 리스료 1,558,700**.

## 할부 상세

```
이용금액  AB31 = 취득원가 − 선납금
수수료    AB38 = ROUNDDOWN(이용금액 × 수수료율, -2)
월납입액  AB42 = ROUNDUP( PMT(금리/12, 기간, −(이용금액 + 수수료), 0), -2 )
```

골든 케이스 (E 200 AMG Line): 차량가 72,000,000 / 60개월 / 금리 5.7% / 선납 30,000,000 / 수수료율 0.18%
→ 이용금액 42,000,000 / 수수료 75,600 → **월 납입액 807,600**.

## 자동 산정 (참조테이블 추출 완료)

- **잔가율** ✅ 모델·기간별 잔가율표(엑셀 `AA110:AD238`) → `data/residual-rates.json`(93종).
  `resolveOrixResidualRate(모델, 기간, 주행거리)` = 최대잔가 + 주행거리 조정(±3%).
- **금리** ✅ 상품별 기준금리 + 보증금구간 추가금리 + 선수가산 → `data/rates.json`.
  `resolveOrix*Rate(...)`. 운용 5.2% / 금융 5.5% / 할부 5.7% 기준.
- **통합**: `quoteOrixOperatingLease(캡처필드)` → 잔가·금리 자동 조회 후 월납입까지.

- **자동차세** ✅ 배기량 구간별 세율(≤1000:104, ≤1600:182, 초과:260 원/cc, 교육세 포함) → `vehicle-tax.ts`.
  S 500 4M(3,982cc) → 연 1,035,320 / 월 86,300 (엑셀 BB8/P26). 배기량은 `vehicles.json`(93종).
- **총리스료** ✅ `quoteOrixOperatingLease`가 순수리스료 + 자동차세(포함 시) + 보험료(포함 시)로 조립.

## 아직 단순화한 부분 (추후 확장)

- **보험료**: 엑셀 P27이 비어 있어(수동/외부) 현재 월 보험료는 선택 입력. 운전연령·대불한도·면책 기반 자동화는 추후.
- **전기차 자동차세**: 배기량 없는 EV는 잠정 정액(130,000/년) — 정책·시트로 재확인 필요.
- **등록세·공채**: 판매사지원/고객별도부담 시 취득원가 기여 0 (골든 케이스 기준). 취득원가포함 조건은 추후 확장.
- **중점차종 조정**(금리 AN53), **협력업체(딜러사)**: 백로그(`architecture.md`).

각 확장은 새 골든 케이스로 검증한다.
