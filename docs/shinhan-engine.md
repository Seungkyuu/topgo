# 신한카드 오토리스 엔진 (역추적)

신한카드 `오토리스(운용&금융)_CA용` 시트를 역추적해 이식한 계산 모델.
구현: `lib/engine/shinhan/auto-lease.ts` · 검증: `lib/engine/shinhan/__tests__/`.

> ⚠ 신한 전용 어댑터. 운용·금융 통합 시트에 3시나리오(AR/AS/AT) 구조.
> 현재는 운용리스(AR17) 이식. 금융리스(AR35)·렌터카는 미착수.

## 계산 사슬 (운용, 엑셀 AR17)

```
월리스료 = ROUNDUP( PMT((금리 + 0.01%)/12, 기간,
                     pv = −(취득원가 + 부대비용) + 보증금 + 선수조정,
                     fv = 잔가 − 보증금), -1 )
```

오릭스 리스와 PMT 구조는 같으나: 금리에 **+0.01% 가산**, 결과 **ROUNDUP(-1)**,
취득원가·부대·보증금·잔가 조립이 신한 고유.

## 골든 케이스 (엑셀 실측 = 코드)

차종 Cayenne Coupe 3.0 / 차량가 148,400,000 / 60개월 / 운용

| 항목 | 값 |
|---|---|
| 취득원가 | 178,631,200 |
| 부대비용 | 7,145,248 |
| 잔가 | 67,090,000 |
| 보증금 | 16,780,000 |
| 금리 | 5.9% (+0.01%) |
| **월 리스료** | **2,537,360** |

(화면 표시 월리스료 H23=2,538,250은 소액 추가분 포함 — 추후 확인.)
