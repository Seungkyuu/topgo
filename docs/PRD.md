# PRD — Lee&Kim 반자동 견적 시스템

원본 기획(PRD)의 **요구사항**은 유지하되, 실제 캐피탈사 엑셀 분석(`excel-analysis.md`)과 배포 환경 재검토를 반영해 아키텍처 전제를 갱신한 요구사항 정의서다.

## 1. 개요

- **명칭**: Lee&Kim 반자동 견적 비교 시스템
- **목적**: 카랩 문의 캡처에서 조건을 추출하고, 캐피탈사별 계산 로직으로 견적을 산출해, 상담사 검수 후 고객에게 문자로 발송하는 반자동 파이프라인.
- **핵심 가치**: 기계는 추출·조회·계산·초안, 사람은 검수·영업 판단·발송 승인.

## 2. 원본 대비 바뀐 전제

| 항목 | 원본 PRD | 갱신 |
|---|---|---|
| 실행 환경 | 로컬 윈도우 PC | 무료 클라우드(Vercel) |
| UI | Streamlit | Next.js 반응형 웹 |
| 엑셀 처리 | xlwings로 실제 Excel COM 구동 | 계산 로직 코드 이식(런타임 엑셀 없음) |
| DB | 로컬 SQLite | Supabase(Postgres) |
| 할인 | 상담사 수동 | GETCHA API(스펙 수령 전 수동 fallback) |
| 발송 | 이미지/PDF 다운로드·복사 | 알리고 SMS 발송 + 화면 요약 |

> 근거: Excel COM 자동화는 클라우드에서 불가·비권장이고, 금융 수식은 코드로 정확히 재현 가능하다(`excel-analysis.md`).

## 3. 기능 요구사항

### 3-1. 템플릿·프로파일 관리
- **REQ-101** 캐피탈사 신규 엑셀을 규칙 파일명으로 보관하고, 잔가율·모델가·금리 등을 추출해 "계산 프로파일"로 등록한다. (파일 드롭 자동 파싱 → 엑셀 자동추출 + 파라미터 관리로 재해석)
- **REQ-102** 조건 입력 시 1차 거래방식 · 2차 브랜드 적합도 · 3차 최신 연월 필터로 계산 프로파일 후보 2~3개를 추천하고 다중 선택(체크박스)을 제공한다.

### 3-2. 입력·AI 파싱
- **REQ-201** 카랩 문의 캡처 이미지를 업로드하면 Claude Vision으로 차량·거래조건·메타 필드를 추출한다. (추출 스키마는 `architecture.md`)
- **REQ-202** 추출 결과를 정보 확인 폼에 자동 기입하고 상담사가 수동 보정할 수 있다.

### 3-3. Human Touch·계산
- **REQ-301** 추가 할인액(원), 잔가 모드(일반/최대 토글), 추가 수수료율(%) 등 영업 변수 제어 UI를 제공한다.
- **REQ-302** 선택된 2~3개 프로파일을 **코드 엔진으로 동시 계산**한다. (엑셀 COM 제약이 사라져 진짜 병렬 가능)
- **REQ-303** (신규) GETCHA 할인가를 조회해 계산에 반영한다. API 스펙 수령 전까지는 상담사 수동 입력으로 대체한다.

### 3-4. 출력·발송
- **REQ-401** 2~3개사 결과(월 납입금·초기비용·잔존가치·영업마진)를 비교 매트릭스로 표시하고 최저 월 납입금을 하이라이트한다. 모바일에서는 세로 스택으로 전환한다.
- **REQ-402** 고객용 견적 요약과 표준 안내 문구를 생성하고 원클릭 복사를 제공한다.
- **REQ-403** (신규) 상담사 검수 후 알리고 SMS/LMS로 고객에게 견적을 발송한다. **발송 전 승인 게이트 필수.**

## 4. 비기능 요구사항
- **NREQ-501** 반응형: PC·태블릿·스마트폰 브라우저에서 레이아웃이 깨지지 않고 Grid↔Vertical Stack으로 전환.
- **NREQ-502** 오발행 방지: 할인이 차량총액 초과 또는 마이너스 마진 임계 도달 시 계산 차단·경고. 유효기간 지난/미검증 프로파일은 상단 경고 배너.
- **NREQ-503** 재현성: 견적마다 사용 프로파일 버전과 입력 스냅샷 저장. (원본 엑셀을 열지 않으므로 임시복사본·원본훼손 이슈는 소멸)
- **NREQ-504** 정합성 검증: 프로파일 활성화 전 실제 엑셀 출력값과 코드 계산값을 골든 케이스로 자동 대조해 전 케이스 통과해야 활성.

## 5. 범위·단계
- 우선: 오릭스 운용리스 수직 슬라이스로 파이프라인 검증.
- 이후: 금융사별 대표상품 1개씩 확장.
- 참조 데이터는 자동 추출 → DB 적재.

## 6. 나중에 확정 (열어둠)
인증·권한, 개인정보 처리 범위(캡처 전화·닉네임 저장, Claude 전송, SMS 정보통신망법 준수), 무료 티어 한도. 상세는 `architecture.md`.
