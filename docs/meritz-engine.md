# 메리츠 렌터카(장기렌트) 엔진 (역추적)

메리츠캐피탈 렌터카 견적시트를 역추적해 이식한 계산 모델.
구현: `lib/engine/meritz/rental.ts` · 검증: `lib/engine/meritz/__tests__/`.

> ⚠ 오릭스와 완전히 다른 구조. 계산이 `견적조건`·`차량정보`·`렌트_입력` 시트에 걸쳐 있고
> 조건 3개(36/48/60개월) 시나리오(BR/CM/DH 열)로 나뉜다. VBA는 UI 잡일뿐.

## 계산 사슬

```
금융분   견적조건!M48 = ROUNDUP(PMT(금리/12, 기간, −원금 + 보증금조정, ROUND(잔가/1.1) − 보증금조정), -2)
공급가   렌트_입력!EG14 = 금융분 + 자동차세 + 보험료 + 정비비 + 차고지(500) + 조합(700) + 멤버쉽(0)
부가세   ROUNDDOWN(공급가 × 0.1, 0)
매회납부 렌트료(월) = 공급가 + 부가세          ← 렌트료에 보험·세금·정비 포함, VAT 포함
```

오릭스 리스와의 차이: **렌트료에 보험·자동차세·정비 포함**, **VAT 10% 포함**, 원금·잔가가 렌트 전용.

## 골든 케이스 (엑셀 실측 = 코드)

차량가 45,000,000 / 36개월 / 잔가율 57% / 금리 6%

| 항목 | 값 |
|---|---|
| 원금(H21) | 39,431,000 |
| 잔가(차량가×57%) | 25,650,000 |
| 금융분(PMT) | 606,800 |
| + 자동차세 / 보험 / 정비 | 2,000 / 58,400 / 106,000 |
| 공급가(VAT별도) | 774,400 |
| 부가세 | 77,440 |
| **매회납부 렌트료(월, VAT포함)** | **851,840** |

동일 차량 48개월 770,550(잔가52%) · 60개월 719,840(잔가47%).

## 다음 단계 (라이브 비교 연동)

현재 엔진은 원금·잔가·보험·정비를 입력으로 받는다. UI의 캐피탈 비교(`capitals.ts`)에
메리츠 장기렌트를 붙이려면 모델별 참조데이터를 추출해야 한다:

- **원금 구성**: 과세표준(차량가/1.1) + 개소세·취득세 + 부대 (견적조건 H17~H25)
- **렌트 잔가율표**: 차량정보 잔가(모델·기간별, 예 36→57%)
- **보험료·정비비표**: 모델·정비상품별
- **자동차세분**: 배기량/EV 기반

각 추출은 새 골든 케이스로 검증한다. 그 전까지 비교표에서 메리츠는 "준비중".
