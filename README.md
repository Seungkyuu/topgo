# Lee&Kim 반자동 견적 시스템

카랩 문의 캡처에서 조건을 추출하고, 캐피탈사별 계산 로직으로 견적을 산출해, 상담사 검수 후 고객에게 문자로 발송하는 반자동 견적 파이프라인.

## 워크플로우

```
카랩 캡처 → AI 추출 → 저장 → GETCHA 할인가 → 계산 엔진 → 견적서 → 상담사 검수 → 알리고 SMS 발송
```

## 기술 스택

- **프론트/호스팅**: Next.js 반응형 웹 · Vercel (무료 티어)
- **DB/저장/인증**: Supabase (Postgres + Storage + Auth)
- **캡처 추출**: Claude Vision
- **계산 엔진**: 캐피탈사 엑셀 로직을 코드 이식(런타임 엑셀 없음)
- **연동**: GETCHA(할인가) · 알리고(SMS)

## 설계 배경

원본 기획은 로컬 윈도우 PC + Excel COM(xlwings) 전제였으나, 자체 서버·사내망이 없고 Excel COM은 클라우드에서 불가·비권장이라 **계산 로직을 코드로 이식하는 무료 클라우드 웹** 구조로 재설계했다. 실제 캐피탈사 엑셀 5종 분석 결과, 복잡도는 금융 수식이 아니라 참조 데이터(잔가율·모델가·보험·세금표)와 분기 규칙에 있으며 금융사마다 구조가 달라 금융사별 어댑터가 필요하다.
